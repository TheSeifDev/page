## 14 — المشروع ليس مجموعة أفراد

المشروع = **نظام + Ownership**. كل جزء لازم يكون له Owner.

**التوزيع الصحيح (مسارات المسؤولية):**

| المسار | المسؤول عن | المهارات المطلوبة |
|---|---|---|
| **Embedded & Hardware Lead** | الدوائر، اختيار الحساسات، معالجة الإشارة، تصدير الداتا (UART/SPI/I2C) | C/C++، إلكترونيات أساسية |
| **Backend & Cloud Architect** | معمارية السيرفر، قواعد البيانات والـ Schemas، تأمين الـ Endpoints | Python/Node، SQL |
| **Frontend & UX Engineer** | لوحة التحكم، الداتا الحية، توافق الموبايل والويب | JS/React، UI أساسي |
| **AI / Data Specialist** | الـ Dataset، التدريب والاختبار، الـ Optimization & Inference | Python، ML basics |
| **Documentation / QA** (دور ثانوي لكل فرد) | Test Cases، التوثيق، الريبورت، العرض | كتابة ودقة |

| Component | Owner | Backup | Status |
|---|---|---|---|
| Firmware + Sensors | أحمد | سارة | [[dot:amber]] Prototype |

**كل عضو لازم يعرف يجاوب:**

> ماذا أملك؟ — ماذا أنجزت؟ — ماذا يعتمد عليّ؟ — ماذا أفعل لو الجزء بتاعي تعطّل؟

## 16 — بروتوكول منع الركوب المجاني [[new]]

الدكتور هيسأل: **"إنت عملت إيه بالظبط؟"** — والإجابات الجماعية العائمة بتوزع الدرجات عشوائياً. الوقاية:

1. **Demo أسبوعي إجباري:** كل أسبوع كل عضو يعرض شغله شغال (مش "كلام عن الشغل")
2. **الـ Commits باسمك:** كل كود بيرفع على GitHub باسماً — سجل الـ commits هو الإثبات الرسمي لجهودك
3. **صفحة المساهمات في الريبورت:** جدول (اسم / موديول / سطر من الإنجاز بأرقام)

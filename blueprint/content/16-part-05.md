## 17 — Functional Requirements

اكتب ما يجب أن **يفعله** النظام، بصيغة رسمية مرقمة:

| ID | Requirement |
|---|---|
| FR-01 | The system shall record temperature readings every 60 seconds per sensor |
| FR-02 | The system shall store readings locally on the device when offline, and sync automatically when connectivity returns |
| FR-03 | The system shall trigger an alert (dashboard + SMS) within 30 seconds of a reading outside 2–8°C |
| FR-04 | The administrator shall generate a per-trip temperature report (PDF) |
| FR-05 | The system shall maintain a tamper-evident timestamped log per shipment |

## 18 — Non-Functional Requirements

**وهنا معظم الطلاب بيقعوا** — بيكتبوا "زمن استجابة مقبول" — **مقبول إزاي؟** خليها أرقام قابلة للقياس:

| النوع | مثال Measurable (PharmaTrack) |
|---|---|
| Performance | Dashboard يفتح خلال < 2s عند 50 مستخدم متزامن — API p95 < 500ms |
| Reliability | صفر قراءات مفقودة بين الـ offline والـ sync (يتحقق بأرقام تسلسلية) |
| Power | الجهاز يشتغل ≥ 10 ساعات على Power Bank |
| Security | كلمات المرور hashed (bcrypt) — كل الاتصال HTTPS + JWT |
| Usability | صفحة Dashboard واحدة تعرض الحالة الحالية من غير تدريب مسبق |

## 19 — User Stories

**الصيغة:** *As a [user], I want [action], so that [benefit].*

| Role | Story |
|---|---|
| Fleet Manager | As a fleet manager, I want live temperature per vehicle **so that** I can intervene before the medicine spoils |
| Pharmacist | As a pharmacist, I want a signed report at delivery **so that** I can reject a compromised shipment |
| Driver | As a driver, I want SMS alerts **so that** I can check the fridge immediately |
| Admin | As an admin, I want to add/remove devices **so that** I can manage the fleet |

## 20 — Traceability: من المتطلب للإثبات [[new]]

كل FR لازم يكون له **اختبار + مكان في العرض**. ده الجدول اللي بيقفل دايرة (المتطلب ← التنفيذ ← الاختبار ← المناقشة):

| FR | اللي بينفذه | الـ Test Case | فين في الـ Demo |
|---|---|---|---|
| FR-01 | Firmware (أحمد) | TC-01 | دقيقة 1 من الديمو |
| FR-02 | Firmware + API | TC-03 | دقيقة 2 (سيناريو قطع النت) |
| FR-03 | API + SMS | TC-04 | دقيقة 3 (تنبيه مباشر) |

> لو في Requirement مش ليه Test Case — يبقى إما مش مهم (احذفه) أو مش مطبق (ظبطه).

## 26 — لا تجعل مشروعك رهينة لخدمة واحدة

لو المشروع بيعتمد على API / Cloud / AI Provider / إنترنت / هاردوير — اسأل:

> **"إيه اللي هيحصل لو الجزء ده اختفى بكرة؟"**

## 27 — Dependency Risk Matrix

| Dependency | Importance | Failure Impact | البديل |
|---|---|---|---|
| Internet (في النقل) | High | High | Offline-First + مزامنة عند الرجوع |
| SMS Gateway | Medium | High | تنبيه الـ Dashboard هو المصدر الأساسي |
| Cloud DB | High | High | Local test DB + dumps يومية |
| ESP32 / Sensor | High | High | قطعة احتياطية + **وضع Simulation للديمو** |

## 28 — جدول الخدمات الخارجية (API Keys & Quotas) [[new]]

**مفاجأة كلاسيكية:** الـ free tier بينتهي قبل المناقشة بأسبوعين.

احتفظ بجدول من أول يوم:

| الخدمة | الطبقة المجانية | حد الاستخدام | تنبيه/انتهاء | البديل |
|---|---|---|---|---|
| SMS Provider | 100 msg/شهر | كل تنبيه = رسالة | راقب الشهر دي | Email + Dashboard alert |
| Cloud Hosting | Free tier | ساعات نوم | — | تشغيل محلي للديمو |

> **قاعدة:** أي Feature معتمدة على API مدفوع — لازم يكون لها fallback أو تكون مستعد تدفع.

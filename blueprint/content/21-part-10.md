## 34 — ماذا يحدث عندما يفشل النظام؟

**سؤال بيحب يمسك فيه الممتحنين** — والفريق اللي مجاوبش بيه بيلخبط لايف.

| الحالة | السلوك الصحيح (PharmaTrack) |
|---|---|
| Internet disconnected | تخزين محلي + timestamps محلية + مزامنة عند الرجوع |
| Empty data (رحلة من غير قراءات) | رسالة "لا توجد بيانات" واضحة — مش صفحة فاضية أو crash |
| Invalid input (قراءة نصية/مشوهة) | Validation → تجاهل القراءة → تسجيل error |
| Duplicate request | رقم تسلسلي يمنع التكرار (idempotency) |
| Sensor failure | كشف فقدان الـ heartbeat → تنبيه "الجهاز صامت" |
| Server unavailable | Retry بـ exponential backoff |
| API timeout | 3 محاولات → fallback → إشعار المستخدم |
| Wrong permissions | 403 من غير كشف مسارات داخلية |
| Expired session | Redirect للـ login من غير فقدان حالة الشاشة |

## 35 — Fail-Safe Thinking

لكل Component ارسم الدورة دي:

```diagram
Normal State → Failure → Detection → Fallback → Recovery
```

**مثال:** `API Timeout → Detect (timeout) → Retry ×3 → Fallback (queue محلي) → Notify User`

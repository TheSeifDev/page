## 36 — Security Minimum Checklist (+ إزاي ترد لما يسألوك "ليه؟")

| [[box]] | البند | جواب المناقشة في سطر |
|---|---|---|
| [[box]] | Passwords مش plaintext | "bcrypt — بطيء عمداً ضد brute-force" |
| [[box]] | Authentication صحيح | "JWT موقّع بـ secret مع انتهاء صلاحية" |
| [[box]] | Authorization مفروض | "كل endpoint بيتحقق من الدور قبل التنفيذ" |
| [[box]] | Input validation | "يمنع SQL injection وtype confusion" |
| [[box]] | Secrets خارج الكود | ".env + .gitignore — المفاتيح عمرها ما بترفع GitHub" |
| [[box]] | HTTPS | "يمنع sniffing على الشبكات العامة" |
| [[box]] | رسائل خطأ عامة | "من غير تكشف أسماء مستخدمين صحيحين" |
| [[box]] | File upload validation | "نوع + حجم + اسم عشوائي للتخزين" |

> لو نفذت 8 بنود دول — انت أأمن من 90% من مشاريع التخرج، **ولديك إجابة جاهزة لكل "ليه؟"**

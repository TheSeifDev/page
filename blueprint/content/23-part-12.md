## 37 — Database Design

قبل كتابة أي SQL — حدد: Entities، Relationships، Primary/Foreign Keys، Constraints، Indexes. ثم ارسم **ERD**.

**ERD مصغّر (PharmaTrack):**

```erd
DEVICE (id, name, status) ──< READING (id, device_id, temp, ts, synced)
SHIPMENT (id, from, to, start_ts, end_ts) ──< READING
USER (id, role, hashed_pw) ──< ALERT (id, reading_id, type, ts_sent)
```

> لاحظ: كل قراءة مربوطة بجهاز وشحنة — علاقات طبيعية = اختيار SQL صح (PART 24).

## 38 — Data Lifecycle

كل Data لازم تعرف رحلتها:
**Collection → Processing → Storage → Usage → Retention → Deletion**

خصوصاً لو البيانات شخصية (مرضى/طلبة) — "إزاي بتمسحها ومنهي بيقدر يشوفها؟" سؤال التزام أخلاقي بيسألوه.

## 39 — بيانات التجربة ≠ بيانات حقيقية [[new]]

- **أبداً ما تختبرش على بيانات شخصية حقيقية** (مرضى/أرقام قومية) — استخدم بيانات مولّدة أو anonymized
- وثّق مصدر كل بيانات في الـ Report — "الداتا منين؟" سؤال المناقشة الأول في أي مشروع AI

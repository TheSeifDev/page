## 40 — AI ليست Feature سحرية

لا تقل "استخدمنا AI" — اشرح:
ما المشكلة؟ — ما الـ Input؟ — ما الـ Output؟ — ما الـ Model و**ليه هو بالذات**؟ — الـ Dataset منين وحجمه إيه؟ — إزاي اتجّه؟ — إزاي اتدرّب؟ — إزاي اتحقّم؟ — **ما الـ Baseline؟** — ما حدود النموذج؟

## 41 — AI Evaluation

**"النتائج شكلها ممتاز" ليست تقييم.** حدد Metrics مناسبة لنوع المهمة:

| نوع المهمة | Metrics المناسبة |
|---|---|
| Classification ( anomaly detection ) | Precision, Recall, **F1** |
| Regression ( توقع قيمة ) | MAE, RMSE |
| Detection/Retrieval | IoU, mAP, Precision@k |

## 42 — قاعدة الـ Baseline [[new]]

> **قبل أي Model — اعمل baseline بسيط (قاعدة/عتبة) وقيّسه.**

**مثال PharmaTrack:**

- Baseline: عتبة بسيطة (خارج 2–8°C = anomaly) حققت **F1 = 0.71**
- Model: Isolation Forest حقق **F1 = 0.89**
- **القيمة المضافة للـ AI = +0.18 + كشف أنماط مبكرة قبل تجاوز العتبة**

Model بلا baseline = "شكلها ممتاز". Model بـ baseline = **إثبات علمي**.
وسؤال الممتحن المفضل بيترد تلقائياً: *"ليه مفيش حل أبسط يعمل نفس الوظيفة؟"* — إنت جاوبت قبل ما يتسأل.

## 43 — صدق الداتا + الـ Data Leakage [[new]]

**أكبر فخ بيسقط فيه الطلاب في مشاريع الزمن (time-series):**

لو قسمت الداتا **عشوائي** train/test — القراءة رقم 100 ممكن تكون في التدريب والـ 101 في الاختبار وهما متتاليتين → النموذج "بيغش" → دقة وهمية 99% تنهار في الواقع.

**الحل:** Split **بالزمن** — الأقدم للتدريب، الأحدث للاختبار. ووثّق: المصدر، الحجم، التوزيع، طريقة التقسيم.

## 44 — بطاقة حدود النموذج (Model Limits Card) [[new]]

اكتب بصراحة (الصدق = مصداقية في المناقشة):

| بند | مثال |
|---|---|
| بيطبّق على | أجهزة PharmaTrack بعد 3 أسابيع قراءات |
| **مبيطبّقش على** | أجهزة جديدة من غير فترة قراءات، أنواع ثلاجات غير ممثلة في الداتا |
| الدقة المتوقعة | F1 = 0.89 على data الاختبار |
| يفشل لما | توزيع الحرارة يبعد عن توزيع التدريب (Concept Drift) |

## 46 — Hardware Failure Matrix

| Component | Failure | Detection | Response |
|---|---|---|---|
| Sensor | No data | Timeout على القراءة | Alert + قطعة احتياطية |
| ESP32 | Offline | فقدان Heartbeat | إعادة اتصال تلقائية |
| Network | Lost | Connection check | تخزين محلي + retry |
| Server | Down | Health check | Fallback محلي للديمو |

## 47 — ميزانية وسلامة وتوقيت الشراء [[new]]

**جدول الميزانية (PharmaTrack):**

| القطعة | الكمية (منها احتياطي) | ملاحظة |
|---|---|---|
| ESP32 | **2** | واحدة شغالة + واحدة احتياط للديمو |
| DS18B20 (سنسور حرارة) | **3** | السنسور بيبوظ كتير |
| Power Bank + أسلاك | 2 | |
| PCB/Breadboard + Jumpers | مجموعة | |

**قواعد ذهبية:**

- **اشترِ 2 من كل قطعة حرجة** — القطعة البايظة يوم الديمو مش ليها حل تاني
- **اطلب المكونات أول 3 أسابيع** — الشحن من بره بياخد 2–6 أسابيع؛ التأخير قاتل للمشاريع المدمجة
- **السلامة:** لا تغذّ 5V على مدخل 3.3V — Common Ground للدائرة كلها — لا تترك الدائرة شغالة بلا مراقبة أول مرة

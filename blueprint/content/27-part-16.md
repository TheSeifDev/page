## 51 — Git Workflow

```tree
main (محمي — نسخ العرض والتسليم)
  └── develop (التجميع)
        └── feature/xxx (فرع لكل ميزة → Pull Request → مراجعة زميل → Merge)
```

**ولا تجعل أبداً:** `final-final-v2-real-final.zip` — ده مش ملف، ده اعتراف بعدم وجود نظام.

## 52 — Commit Discipline

| ❌ | ✅ |
|---|---|
| `update` | `feat: add offline sync queue` |
| `fix bug` | `fix: handle duplicate readings on sync` |
| `changes` | `docs: add test plan for alerts` |

**قواعد إضافية:**

- `.gitignore` من أول commit: `.env` — `node_modules` — build artifacts — **أي مفاتيح** (يقفل ثغرة الـ security في PART 11)
- Commit صغير ووصفه imperative — الهدف: تاريخ المشروع يتقرأ كقصة

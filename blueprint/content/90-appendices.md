## APPENDIX D — كارت جيب المناقشة (Pocket Card) [[new]]

1. **إيه الجديد؟** → ركيزة من التلاتة (محلي/تكلفة/تكامل)
2. **إنت عملت إيه؟** → موديلي + دليل (commits/insights)
3. **ليه X مش Y؟** → السبب من Decision Log
4. **لو فشل X؟** → الفallback من Failure Matrix
5. **معرفش؟** → اعترف → خمّن بعلم → Future Work
6. **الصيغة الذهبية:** اعترف بالحد → اشرح القرار → اعرض البديل

## APPENDIX E — Glossary (مصطلح = سطر) [[new]]

| المصطلح | معناه في سطر |
|---|---|
| **MVP** | أقل نسخة تثبت إن الفكرة شغالة |
| **PoC** | إثبات سريع إن أصعب جزء ممكن |
| **MoSCoW** | تقسيم الميزات: Must/Should/Could/Won't |
| **Scope Creep** | تضخم النطاق بالتدريج من غير قرار |
| **FR / NFR** | متطلبات وظيفية / غير وظيفية (أداء وأمان) |
| **User Story** | "بصفتي X عايز Y عشان Z" |
| **ERD** | مخطط الكيانات والعلاقات في الداتابيز |
| **CRUD** | إنشاء/قراءة/تحديث/حذف — العمليات الأساسية |
| **API / Endpoint** | نقطة اتصال بين أنظمة |
| **REST** | أسلوب تصميم APIs على HTTP |
| **JWT** | توكن موقّع يثبت هويتك بين الطلبات |
| **Hashing (bcrypt)** | تشفير غير قابل للرجوع للباسوردات |
| **SQL Injection** | إدخال كود عبر الحقول — يمنع بالـ validation |
| **Idempotency** | تكرار نفس الطلب لا يكرر الأثر |
| **Heartbeat** | إشارة حياة دورية من الجهاز — فقدانها = عطل |
| **Offline-First** | التصميم يفترض انقطاع النت ويتعافى |
| **WebSockets** | قناة مفتوحة لبث البيانات لحظياً |
| **Monolith / Microservices** | نظام واحد / خدمات موزعة منفصلة |
| **RAG** | تغذية الـ AI بمصادر بيانات محددة |
| **Baseline** | حل بسيط للمقارنة — بدون موديل ذكي |
| **Overfitting** | الموديل حفظ بيانات التدريب بدل ما يتعلم |
| **Data Leakage** | تسريب معلومات الاختبار للتدريب = نتائج وهمية |
| **Precision / Recall / F1** | دقة التنبيهات / نسبة الالتقاط / المتوسط التوافقي |
| **Inference** | تشغيل الموديل المدرب على بيانات جديدة |
| **ESP32** | ميكروكنترولر بشبكة مدمجة — عمود مشاريع IoT |
| **UART/SPI/I2C** | بروتوكولات تواصل الميكروكنترولر مع القطع |
| **Firmware** | الكود المدمج اللي بيشتغل على العتاد |
| **Git / Branch / Commit** | تتبع النسخ / مسارات موازية / لقطة تغيير موصوفة |
| **Pull Request** | طلب دمج فرع بعد مراجعة |
| **Feature Freeze** | منع الميزات الجديدة قرب التسليم |
